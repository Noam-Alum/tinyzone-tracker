A high-performance, real-time status tracker for active TinyZone mirror domains.

## Features

- **Real-Time Monitoring:** Automatically verifies mirror domains every 30 minutes.
- **Categorization:** Distinguishes between **Original** portals and **Replica** mirrors.
- **Quick Watch:** One-click access to the best available portal.
- **Mobile Optimized:** Clean, responsive design for all devices.
- **Automated Updates:** CI/CD pipeline ensures the list stays fresh without manual intervention.
